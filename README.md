# satellite  
**Jewelry Personal Styling & Online Select Shop**

## Overview
**satellite**는 온라인 주얼리 환경에서 발생하는 선택의 불확실성과 결정 피로를 줄이기 위해 기획된  
주얼리 퍼스널 스타일링 컨설팅 브랜드이자 온라인 편집숍입니다.

두께감, 장식성, 무드와 같이 온라인에서 전달되기 어려운 감각 요소를  
**Typology System**으로 구조화하여, 사용자가 자신의 취향을 명확히 이해하고  
일관된 기준으로 주얼리를 선택할 수 있도록 설계했습니다.

## Role
- Brand Identity & Experience Design  
- UX·UI Design (Web / App)  
- Web Publishing (Desktop Demo)  
- Packaging Design  

> 개인 프로젝트로 전 과정을 단독 수행했습니다.

## Key Design Focus
- **Typology System**  
  주얼리 인상을 *Fancy–Simple*, *Thin–Bold* 두 축으로 구조화하여  
  취향 탐색과 비교 과정을 직관적으로 설계했습니다.
- **Consistent Brand Experience**  
  브랜드 아이덴티티, 웹·앱 UX, 패키지까지 하나의 기준으로 연결했습니다.
- **Reduced Decision Fatigue**  
  과도한 탐색을 줄이고, 선택에 대한 확신을 돕는 경험 설계를 목표로 했습니다.
